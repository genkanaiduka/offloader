❓ よくあるご質問 (FAQ)

対応しているカメラカードや外部ドライブは？ ▼
CFexpress Type A / B、RED Mini-Mag、CFast 2.0、SDカード（UHS-II / UHS-I）、microSD など、macOS が認識するすべてのメディアカードに対応しています。また、書き出し先ストレージも NVMe ポータブル SSD、RAID 0/5 アレイ、大容量 HDD、ネットワークドライブ（NAS / SMB）に対応しています。
チェックサム（xxHash64, MD5, SHA-256）はどれを選ぶべきですか？ ▼
撮影現場での高速オフロード: 圧倒的な超高速計算が可能な xxHash64 がおすすめです。ドライブの物理最大転送速度（1000MB/s超）を落とさずに完全照合できます。
映画スタジオやポストプロダクション規定: 業界納品規定でハッシュアルゴリズムが指定されている場合は MD5 または SHA-256 を選択してください。
カードやドライブのアクセス権限エラーが出る場合は？ ▼
macOS のセキュリティ機能により、外部ボリュームへのアクセス許可が必要な場合があります。
1. Macの「システム設定」>「プライバシーとセキュリティ」を開きます。
2.「ファイルとフォルダ」を選択し、Offloader の「リムーバブルボリューム」にチェックが入っていることを確認してください。
3. アプリを再起動すると正常にアクセスできるようになります。
オフロード検証レポート（PDF）はどこに保存されますか？ ▼
転送完了時、各バックアップ先ドライブ（ターゲット）のコピー先フォルダ直下に、チェックサム照合結果、ファイルハッシュ一覧、転送時間、撮影メディア詳細をまとめた PDF レポートが自動生成されます。
サブスクリプション（月額課金）や追加料金はありますか？ ▼
いいえ。Offloader は 100% 買い切りの永久ライセンスです。月額費用やサブスクリプション、追加のアプリ内課金は一切ありません。

❓ Frequently Asked Questions

What camera cards and storage drives are supported? ▼
All media cards recognized by macOS are supported, including CFexpress Type A & B, RED Mini-Mag, CFast 2.0, SD cards (UHS-II/UHS-I), and microSD. Destination drives include NVMe SSDs, RAID storage arrays, spinning HDDs, and network storage (NAS / SMB).
Which checksum algorithm should I choose (xxHash64, MD5, SHA-256)? ▼
For on-set DIT work: We strongly recommend xxHash64. It delivers extreme speed without bottlenecking high-performance NVMe drives (1000+ MB/s) while providing cryptographic-grade bit-exact verification.
For studio deliverables: Choose MD5 or SHA-256 if your production workflow or post-facility mandates it.
Card or Drive Access Permission Issues? ▼
macOS security requires explicit permission to access external volumes:
1. Open macOS System Settings > Privacy & Security.
2. Select Files and Folders and verify Offloader has permission for Removable Volumes.
3. Relaunch the application.
Where are offload verification reports (PDF) saved? ▼
Upon successful offload and checksum verification, a comprehensive PDF report is automatically created in the root of each destination target folder with complete hash logs and metadata.
Are there any recurring subscriptions or hidden fees? ▼
Zero. Offloader is 100% perpetual. No monthly fees, no subscriptions, and no in-app purchases.
